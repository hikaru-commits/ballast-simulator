# v1.8.1 Blank Screen Fix

Cause: `BottomPanel` used `useSimStore(s => s.alarms.filter(...))`. With Zustand v5 this selector returns a new array for every snapshot, which can trigger a React external-store render loop and leave the page blank.

Fix: subscribe to the stable `alarms` array reference first, then filter active alarms after selection inside the component.

No hydraulic logic from v1.8 was reverted.
