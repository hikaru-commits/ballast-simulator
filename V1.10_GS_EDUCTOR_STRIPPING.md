# v1.10 — GS Pump / Eductor / Stripping Main redesign

- Tank display order changed to No.1 → No.4 from top to bottom on both PORT/STBD sides.
- Added dedicated GS Pump (`GS1`) with sea suction valve `V-GS-S` and motive discharge control valve `V-GS-D`.
- Eductor motive water is no longer taken from the ballast-pump common discharge header.
- Added dedicated stripping main connected to all ballast tanks through individual `*-STR` valves.
- `V-WES1` connects the stripping main to Eductor No.1 suction.
- Eductor suction flow now physically removes water from selected stripping tanks.
- Eductor vacuum depends on GS pump motive pressure/flow.
- Scenario Workshop 01 guidance updated for GS Pump → motive water → vacuum → stripping sequence.
