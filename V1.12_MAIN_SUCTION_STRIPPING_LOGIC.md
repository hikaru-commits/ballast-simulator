# v1.12 Main suction / stripping logic

Training-model changes:

- Main ballast-pump deballasting is fast but cannot drain below the main suction pickup region.
- Main suction flow begins tapering below 2.0 m tank level and reaches zero at 1.0 m.
- As the level approaches the pickup, simulated suction pressure falls and warnings are generated.
- The simulator prevents the main pump from numerically draining below 1.0 m.
- Remaining water is removed by the stripping system / eductor.
- Eductor stripping is deliberately slower (max about 240 m3/h) but can continue down to a near-empty residual level (~0.02 m).
- GS Pump has been reduced to a training rated capacity of 600 m3/h and 0.65 MPa. This is a simulator assumption, not an actual vessel data value.
- A DEBALLAST LIMIT status card is added to the side panel.

These thresholds are editable simulator parameters in `src/store/useSimStore.ts`:

- `MAIN_SUCTION_TAPER_START_LEVEL`
- `MAIN_SUCTION_MIN_LEVEL`
- `EDUCTOR_RESIDUAL_LEVEL`
- `GS_RATED_FLOW`
- `GS_RATED_PRESSURE`
