# v1.8 hydraulic line-up logic fix

## Root cause of the false alarms in v1.7
v1.7 treated more than one discharge category as a hard conflict (`sinkCats > 1`). Therefore opening both PORT and STBD discharge selectors with valid tank valves made `hasSink=false`; every running pump was then also diagnosed as DEADHEAD. This produced both `MULTIPLE DISCHARGE DESTINATIONS` and `DEADHEAD` for a physically valid simultaneous P/S ballasting lineup.

## v1.8 changes
- PORT + STBD tank discharge destinations are allowed simultaneously.
- PORT + STBD tank suction sources are allowed simultaneously.
- Total pump flow is divided among all active tank branches instead of being duplicated to each side.
- Hard conflicts are now limited to contradictory topology:
  - same side connected to both common suction and common discharge;
  - sea chest and ballast tanks simultaneously selected as different suction source types;
  - overboard and ballast tanks simultaneously selected as different discharge destination types.
- DEADHEAD occurs only when a running pump has no valid discharge destination.
- Alarm state is now current-state based. Resolved transient alarms disappear from the ALARMS pane; event history remains in EVENT LOG.
