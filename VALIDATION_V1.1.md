# v1.1 Validation Checklist

1. Port tank valve cannot establish a route through STBD MAIN unless the forward common cross valve is open.
2. Starboard tank valve cannot establish a route through PORT MAIN unless the forward common cross valve is open.
3. Pumped ballast requires a sea chest SUC route, pump suction/discharge valves, a selected side-main DIS route and an open destination tank valve.
4. Pumped deballast requires an open source tank valve, selected side-main SUC route, pump suction/discharge valves and overboard or intentionally opened sea-chest discharge route.
5. Gravity fill uses sea chest DIS connection and side-main DIS selector with pumps stopped.
6. Gravity discharge uses side-main SUC selector and sea chest SUC connection with pumps stopped.
7. Opening only an overboard valve does not generate flow in a dead-ended ballast main.
8. Opening the forward common valve can cross-connect Port and Starboard mains; an INFO alarm is generated to make the configuration conspicuous.
9. Connecting the same side main to both suction and discharge headers generates a caution alarm.
10. High pickup becomes unavailable for suction below the modeled high-pickup level.
