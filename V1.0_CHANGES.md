# v1.0 — Realistic dual-main routing upgrade

This version restructures the generic training vessel ballast system around a more realistic dual reversible main arrangement.

## New hydraulic architecture
- Main A: connected to each tank HIGH pickup.
- Main B: connected to each tank LOW pickup.
- Both mains are bidirectional; there is no tank-side SUC/FILL valve type.
- Aft and forward section isolation valves on both mains.
- Dedicated Fore Peak common isolation valves for Main A and Main B.
- Main A / Main B suction selector valves to the common pump suction header.
- Main A / Main B discharge selector valves from the common pump discharge header.
- Three parallel ballast pumps, each with suction valve and adjustable discharge valve.
- Port and starboard sea chests and overboards.
- Gravity crossover between suction and discharge headers.

## Simulation changes
- Actual flow animation is generated only on a complete source-to-sink route.
- Dead-ended water-filled lines remain wet but have no moving flow animation.
- Tank valves can be used in either direction depending on the selected hydraulic route.
- Section isolation valves determine which tank zones are hydraulically reachable.
- Pump deadhead, dry-running, high starting current and conflicting source/sink routing alarms remain active.
- Pump flow now includes a simplified route-resistance/load factor.
- Gravity fill/discharge uses current draft, heel, trim and tank liquid-surface elevation.
- Draft, trim, heel, free-surface correction and effective GM remain coupled to tank quantities.

## Important limitation
This is still a generic educational hydraulic model, not a validated model of a specific vessel. Real ship P&ID, pump curves, valve Cv/Kv, tank sounding/FSM tables, hydrostatics and pipe-loss data are required before using it as a vessel-specific engineering simulator.
