# v1.6 UI compact redesign

- Desktop operator screen is constrained to one viewport.
- P&ID and ship attitude are always visible together by default.
- Right-side information is reduced to ship condition, active route, stability, and selected equipment control.
- Gravity details and Quick Guide are collapsed by default.
- Full alarm/event history moved to a bottom drawer opened by ALARMS / LOG.
- HIDE PANEL and HIDE ATTITUDE buttons allow maximum P&ID area.
- Responsive fallback keeps the application usable on narrower screens.
