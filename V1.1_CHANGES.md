# v1.1 — Port / Starboard Dual-Main Manifold

- Replaced abstract Main A/B with physical PORT BALLAST MAIN and STBD BALLAST MAIN.
- Port WBT branches connect only to Port Main; starboard WBT branches connect only to Starboard Main.
- Added forward common cross-connection valve between Port and Starboard mains.
- Added independent pump-room selector valves:
  - Port Main → Pump Suction
  - Starboard Main → Pump Suction
  - Pump Discharge → Port Main
  - Pump Discharge → Starboard Main
- Added dual-route sea chest manifold. Each Port/Stbd sea chest can be connected independently to:
  - Pump suction header
  - Pump discharge header / gravity route
- Tank HIGH and LOW valves remain reversible and both discharge/fill through the tank's own-side ballast main.
- Gravity filling no longer requires an artificial gravity bypass: Sea Chest DIS → Discharge Header → Main → Tank.
- Gravity discharge: Tank → Main → Suction Header → Sea Chest SUC.
- Flow animation is shown only on a continuous active hydraulic route. Wet but dead-ended lines stay static.
- Active Hydraulic Route panel now reports PORT MAIN and STBD MAIN flow separately.
