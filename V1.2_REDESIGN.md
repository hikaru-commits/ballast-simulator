# v1.2 — P&ID Redesign / Training Layout Reset

The v1.1 screen became difficult to trace because physical tank lines, pump-room selector lines, labels, and long vertical continuations overlapped. v1.2 redesigns the P&ID around training readability while preserving the v1.1 hydraulic valve IDs and simulation logic.

## Non-negotiable routing model
1. PORT WBTs connect only to PORT BALLAST MAIN.
2. STBD WBTs connect only to STBD BALLAST MAIN.
3. Each WBT has HIGH and LOW reversible branch valves. They are not fixed SUC/FILL valves.
4. The two side mains remain physically separate along the ship.
5. The FORE COMMON/CROSS valve is the intentional cross-connection between PORT and STBD mains.
6. In the pump room each side main has two independent selector paths:
   - MAIN -> COMMON SUCTION HEADER
   - COMMON DISCHARGE HEADER -> MAIN
7. Ballast pumps are parallel between common suction and common discharge headers.
8. Port and starboard sea chests can be connected independently to suction or discharge/gravity header.
9. Overboards are separate branches from the discharge header.
10. Flow animation is permitted only for a complete source-to-sink path; wet/dead-ended pipe is static.

## Drawing rules introduced in v1.2
- Tank arrangement and pump-room manifold are separate visual zones.
- Long vertical pipes connecting both zones are replaced by clearly named continuation markers.
- PORT and STBD mains have distinct labels and remain horizontal and uninterrupted.
- Tank branch valve IDs are placed in dedicated label boxes, not on top of the mains.
- Main isolation valves occupy intentional blank gaps.
- Pump room is divided into three blocks: selector manifold / pumps / sea chest-overboard manifold.
- Sea chest and overboard lines do not cross pump symbols or valve labels.
- Every selector valve sits directly on the line whose function it controls.

This remains a generic educational P&ID. Ship-specific use requires replacement with approved vessel P&ID, pump curves, valve data and hydrostatic/tank tables.
