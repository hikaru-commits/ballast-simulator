# v1.3 — Simple Tank Valve Layout

- Each ballast tank now has exactly one reversible tank valve.
- Removed HIGH/LOW tank valve distinction from UI and hydraulic logic.
- PORT WBTs connect to PORT BALLAST MAIN only.
- STBD WBTs connect to STBD BALLAST MAIN only.
- AFT PEAK is simplified to PORT MAIN and FORE PEAK to STBD MAIN for the current training vessel model.
- Removed intermediate section-isolation valves from the tank-plan display and hydraulic reachability logic.
- Forward cross valve remains as the only tank-area connection between PORT and STBD mains.
- Filling vs deballasting direction is determined entirely by pump-room selector lineup, pump operation, sea chest/overboard configuration, and pressure/head conditions.
- Tank valve pipe key changed from HS/LS branches to a single `<tank>_BR` branch.
