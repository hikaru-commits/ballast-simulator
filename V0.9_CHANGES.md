# v0.9 changes

- Removed separate per-tank FILL valve from the visible P&ID and valve initialization.
- HIGH and LOW tank valves are now bidirectional tank isolation valves. Their role is inferred from the active hydraulic route: sea/pump pressure makes them filling valves; tank-to-overboard pressure makes them suction valves.
- Reworked tank-area P&ID into two clearly named longitudinal ballast mains.
- Added a boxed FORE MANIFOLD with two common forward isolation valves before the Fore Peak branches.
- Enlarged valve ID labels and added dark label backgrounds so IDs remain readable over pipes/tanks.
- Added HIGH/LOW text beside each tank branch and a P&ID legend explaining direction logic.
- Actual-flow animation remains source-to-sink only; merely water-filled or dead-ended pipe has no dashed flow animation.

Training approximation note: this is a generic educational hydraulic model, not an as-built vessel P&ID. Main routing and valve nomenclature should be replaced with the target vessel's approved drawings before ship-specific training use.
