# v1.11 Stripping topology revision

- Keeps the normal ballast system separate from stripping.
- Every P/S WBT has one normal reversible ballast valve to the ballast main and one dedicated stripping valve to the stripping branch.
- P1–P4 stripping branches join the port stripping riser; S1–S4 join the starboard stripping riser.
- Both stripping risers join the COMMON STRIPPING MAIN.
- COMMON STRIPPING MAIN -> V-WES1 -> eductor suction throat.
- GS sea chest -> V-GS-S -> GS pump -> V-GS-D -> V-WER1 -> eductor motive inlet.
- Eductor mixed discharge -> overboard.
- Eductor symbol revised to a converging throat / diffuser representation with separate motive, suction and discharge ports.
- Stripping flow remains independent of the normal ballast tank valve and only occurs when the tank STR valve, V-WES1, eductor vacuum and motive-water conditions are established.
